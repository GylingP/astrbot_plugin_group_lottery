# Group Lottery 

`Group Lottery` 插件是一个用于在QQ群中进行抽奖活动的工具，支持创建、参与、加权和匿名抽奖。该插件提供了丰富的功能和配置选项，适合群主和管理员进行群内抽奖活动的管理。以下是该插件的详细使用说明。

## 功能概述

1. **创建抽奖**：群主可以创建新的抽奖活动，设置中奖人数、冷却期、加权规则以及是否记录历史数据。
2. **参与抽奖**：群成员可以参与正在进行的抽奖，系统会自动检测是否符合参与条件。
3. **加权抽奖**：支持根据用户参与次数对用户进行加权，增加中奖概率。
4. **匿名抽奖**：可以选择是否在抽奖结束后显示中奖者的用户名。
5. **查询和删除抽奖**：支持查询当前或历史的抽奖信息，也可以删除未完成的抽奖活动。

## 命令列表

### 1. `/新建抽奖` - 创建抽奖

**格式**：

```
/新建抽奖 [抽奖名称] [中奖人数] <冷却次数> <按历史频次降权> <是否匿名>
```

**功能**：

* 该命令允许群主创建一个新的抽奖活动。
* `抽奖名称`：用于标识抽奖，不能为空。
* `中奖人数`：设置每轮抽奖的中奖人数。
* `冷却次数`：设定每人中奖后的冷却次数，避免过于频繁地中奖。
* `按历史频次降权`：0表示不加权，1表示根据用户参与次数加权。
* `是否匿名`：0表示记录中奖者信息，1表示此次抽奖不记录。

### 2. `/参与抽奖` 或 `/p` - 参与抽奖

**格式**：

```
/参与抽奖 [抽奖名称]
```

**功能**：

* 群成员可以使用该命令参与当前进行中的抽奖。
* 系统会检查是否满足冷却期、是否已参与等条件。

### 3. `/一键抽奖` 或 `/一键开奖` - 执行抽奖

**格式**：

```
/一键抽奖 [抽奖名称]
```

**功能**：

* 群主可以使用该命令进行抽奖，系统会随机选出中奖者并显示中奖名单。
* 支持加权抽奖和普通抽奖。

### 4. `/查询抽奖` - 查询抽奖状态

**格式**：

```
/查询抽奖 [抽奖名称]
```

**功能**：

* 显示指定抽奖的参与情况，包括已参与的人数、中奖条件、冷却期等信息。
* 若抽奖已结束，还可查看历史中奖记录。

### 5. `/删除抽奖` - 删除抽奖

**格式**：

```
/删除抽奖 [抽奖名称]
```

**功能**：

* 群主可以删除当前进行中的抽奖活动。

### 6. `/抽奖列表` - 查看当前所有抽奖

**格式**：

```
/抽奖列表
```

**功能**：

* 查看群组内所有进行中的抽奖活动，并列出每个抽奖的参与人数、中奖人数等信息。

## 插件配置

* 本插件需要群主权限才能创建和管理抽奖活动。
* 所有抽奖记录会保存在服务器中，并可随时查询历史记录。

## 使用示例

1. **创建抽奖**：
   群主可以使用命令 `/新建抽奖 春季大抽奖 3 5 1 0` 创建一个名为“春季大抽奖”的活动，每轮抽取3人，每人中奖后冷却5次，按照历史参与频次加权，不匿名。

2. **参与抽奖**：
   群成员可以使用 `/参与抽奖 春季大抽奖` 参与抽奖。如果符合条件，会成功加入抽奖列表。

3. **开奖**：
   群主使用 `/一键抽奖 春季大抽奖` 命令进行抽奖，系统将随机抽取中奖者并公布中奖名单。

## 其他注意事项

* 只有群主或管理员可以创建和删除抽奖活动。
* 抽奖过程中用户如果在冷却期内，将不能再次参与。
* 如果选择了加权抽奖，则参与次数较多的用户中奖概率更高。

通过这个插件，群主可以轻松管理群内的各种抽奖活动，增加群成员的互动与参与度。
